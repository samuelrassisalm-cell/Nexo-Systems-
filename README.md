# ⚙️ Nexo Systems | B2B Lead Qualification & Legal Ops Infrastructure

Uma aplicação web desenvolvida para atuar como o principal canal de aquisição e qualificação de leads para uma assessoria de automação e infraestrutura digital. O foco do projeto é o mercado de alto ticket (escritórios de advocacia, clínicas de saúde e empreendimentos imobiliários).

## 🎯 O Problema Resolvido
Empresas de serviços complexos sofrem com gargalos operacionais e perda de tempo atendendo leads desqualificados. O primeiro contato costuma ser desestruturado, dificultando a análise de viabilidade do projeto por parte da equipe técnica.

## 💡 A Solução (Engenharia de Processos)
Desenvolvimento de uma interface minimalista e focada em conversão, integrada a um motor de triagem via JavaScript. 

O sistema atua como um *gatekeeper* (filtro de entrada): o prospecto não consegue contato direto sem antes classificar seu **Segmento de Mercado** e o seu **Maior Gargalo Operacional**. O script processa essas variáveis e estrutura um payload organizado (via URL parametrizada), entregando o lead perfeitamente categorizado para a equipe de vendas iniciar a negociação.

## ⚙️ Funcionalidades Principais (Features)
- **Triagem Inteligente (B2B):** Formulário focado em mapeamento de dores empresariais e setor de atuação.
- **Roteamento Dinâmico de Dados:** Geração de string de contato estruturada via Vanilla JavaScript.
- **UI/UX Corporativa:** Design limpo e autoritário, focado em transmitir credibilidade tecnológica e engenharia de processos.
- **Responsividade Total:** Estrutura otimizada para todas as resoluções utilizando Tailwind CSS.

## 🛠️ Tecnologias Utilizadas (Tech Stack)
- **HTML5:** Estruturação semântica.
- **Tailwind CSS (via CDN):** Estilização utilitária, garantindo carregamento rápido e design system padronizado.
- **JavaScript (Vanilla):** Lógica de negócios, manipulação do DOM e integração de rotas (wa.me API).
